# S10 — Policy file

Read `CLAUDE.md` in full before writing any code. It is the contract. Everything below extends
it and must not contradict it.

## Non-negotiable invariants (already true — keep them true)

- **Fail-closed.** An unknown statement, an unparseable file, an analyzer error, or a panic all
  grade F. No new code path may turn an error, an unknown, or a missing input into a passing
  grade.
- **Determinism.** Identical input produces a byte-identical certificate. Every new input must be
  hashed into `InputDigest`.
- **`internal/domain` imports nothing but stdlib.** Analyzers stay pure functions over a
  changeset: no network, no disk, no git, no database.
- **A rule with no fixture does not exist.**
- Deleting `internal/delivery/` must not break a single engine test.

## Problem

A gate with no legitimate escape hatch gets disabled entirely on the first false positive. The
escape hatch must be documented, scoped, and expiring — never a blanket `--force`.

## Build

`.reversibility.yml`, discovered by walking up from the analysis path.

```yaml
version: 1
gate: A                    # minimum passing grade

ignore:
  - "legacy/**"
  - "**/*.generated.sql"

waivers:
  - rule: PG012
    path: "migrations/0031_*.sql"
    reason: "expand-contract; old code removed in #482"
    expires: 2026-10-01
    approved_by: "vikoit"

overrides:                 # tighten only — never loosen
  - rule: K8S008
    severity: IRREVERSIBLE
```

Rules, all enforced:

- A waiver **requires** `reason` and `expires`. Missing either = config error = the run fails with
  exit 2. Not a warning.
- `expires` is a date, not a duration. Max 180 days from today at parse time; a longer window is
  rejected. An expired waiver is inert and the finding returns.
- A waiver **downgrades a finding to advisory; it never deletes it.** Waived findings still appear
  in the certificate under a `Waived` section with their reason and expiry date. Silent
  suppression is how safety tools die.
- **A waiver cannot cover an UNKNOWN finding or an analyzer error.** Those are fail-closed by
  definition, and a waiver is not permitted to reach them.
- `overrides` may only make a rule stricter. An override that loosens a classification is a config
  error.
- Determinism: hash the resolved config into `InputDigest`. Same code + same config = same
  certificate. Because `expires` compares against the current date, make "today" an injectable
  value in the engine, defaulting to the system date — and pass a fixed date in every test.
- `--config` overrides discovery; `--no-config` disables it.

## Certificate additions

`Waived []WaivedFinding` and `PolicyDigest string`. Bump `SchemaVersion` to 1.1.0.

## Standards

- Go 1.22+, `log/slog`, stdlib `net/http`. No new dependencies — ask before adding anything.
- Table-driven tests, fixtures in `testdata/`, `-race` on, `golangci-lint` clean.
- Maintain 85% coverage on `internal/analyzer` and `internal/engine`.
- Update `CLAUDE.md` in the same session as the change.
- Conventional commits, one logical change per commit.
- `SchemaVersion` bumps on any certificate field change, with a note in `CHANGELOG.md`.

## Do not

- Do not add a second database engine, a rehearsal runner, a web UI, or a hosted service.
- Do not let context, config, or waivers improve a grade.
- Do not invent classification rules or scoring weights.
- Do not weaken determinism for convenience.

Run `make verify`, report what changed, and **STOP**. Do not begin S11 until the owner approves.
